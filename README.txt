PROYECTO INTERACTIVO: UNA SORPRESA PARA DANITZA

Archivos:
- index.html: cinco pantallas interactivas.
- style.css: diseño nocturno, animaciones y adaptación a móviles.
- script.js: navegación, estrellas secretas, velas, carta y sonido.
- fotos/: coloca aquí tus fotografías.

CÓMO ABRIR EN VISUAL STUDIO CODE
1. Extrae el archivo ZIP.
2. Abre Visual Studio Code > Archivo > Abrir carpeta y selecciona esta carpeta.
3. Instala la extensión Live Server (si no la tienes).
4. Abre index.html y pulsa Go Live en la barra inferior.
5. Prueba todos los botones y pantallas.

AÑADIR FOTOS
Copia tus fotografías dentro de la carpeta fotos y nómbralas foto1.jpg, foto2.jpg y foto3.jpg. Si son PNG, cambia las extensiones en las tres etiquetas img de index.html. Usa solo fotos que te sientas cómodo compartiendo.

EDITAR LOS MENSAJES
- Los mensajes secretos están en el arreglo secretMessages de script.js.
- La carta final está en index.html, dentro del elemento con id="letterMessage".
Puedes adaptar las palabras para que suenen realmente tuyas.

PUBLICAR GRATIS CON GITHUB PAGES
1. Crea una cuenta en https://github.com/.
2. Crea un repositorio llamado sorpresa-danitza.
3. Sube index.html, style.css, script.js y la carpeta fotos con las imágenes.
4. Abre Settings > Pages.
5. En Build and deployment, selecciona Deploy from a branch; elige main y /(root), y guarda.
6. Espera la publicación y copia el enlace que aparecerá en esa sección.
Guía oficial: https://docs.github.com/en/pages/quickstart

IMPORTANTE
El enlace publicado será accesible públicamente. No subas fotografías privadas ni datos sensibles.
